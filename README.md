## Features

- Advanced Markdown note templates optimized for rapid Zettelkasten, PARA method, and professional academic research workflows.
- Workflow automation scripts (Templater, DataviewJS) to streamline repetitive daily journaling, task aggregation, and metadata tagging tasks.
- Custom CSS snippet libraries and theme configurations for enhanced visual consistency, readability, and focused writing environments.
- Quick-switch macros and custom hotkey profiles for seamless navigation between the Graph View, Canvas, Outline, and Backlinks panels.
- Pre-configured community plugin stacks (e.g., Tasks, Kanban, Excalidraw, Advanced Tables) for efficient project tracking and visual brainstorming.
- Comprehensive documentation and step-by-step setup guides for all included tools, configuration files, and modules.
- Integration examples and bridge scripts for third-party productivity applications (e.g., Calendar, Google Calendar, Readwise, Logseq).
- System resource optimization configs for faster vault indexing, reduced memory footprint, and optimized handling of massive graph databases.
- Ready-to-use periodic note (daily, weekly, monthly) generation routines with automated template injection and review prompt setups.

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1` / `Install.sh`) to integrate the custom Markdown templates, CSS snippets, and `.obsidian` configuration files directly into your target vault directory. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced Dataview/Templater usage, refer to the `GUIDE.md` file included in the archive.
